# ระบบรับสมัครเรียนออนไลน์ครบวงจร (Online Admission System)
> เชื่อมโยงระบบงานทะเบียนและรองรับการนำเข้าสู่ฐานข้อมูล **ศธ.02** ของกระทรวงศึกษาธิการ

ระบบรับสมัครนักเรียน/นักศึกษาออนไลน์ที่พัฒนาขึ้นเพื่อแก้ปัญหาคอขวดของระบบ Google Form + AutoCrat เดิม โดยเพิ่มความแม่นยำของข้อมูล การจัดเก็บเอกสารอย่างเป็นระบบ การตรวจสอบสถานะแบบเรียลไทม์ และการออกเอกสาร PDF พร้อม Barcode/QR Code มาตรฐาน

---

## 🌟 ฟังก์ชันหลักที่พัฒนาเสร็จสมบูรณ์

### 1. ส่วนสำหรับผู้สมัครเรียน (Front-end Portal)
* **ระบบกรอกใบสมัคร & Data Validation**:
  * ตรวจสอบความถูกต้องของเลขประจำตัวประชาชน 13 หลักด้วยสูตร **Modulo 11 Checksum** แบบเรียลไทม์ (แจ้งเตือนทันทีหากพิมพ์ผิด)
  * จัดรูปแบบเบอร์โทรศัพท์ (08X-XXX-XXXX) และเลขบัตรประชาชน (X-XXXX-XXXXX-XX-X) อัตโนมัติ
  * ตัวเลือกสาขาวิชาเปลี่ยนตามระดับชั้นอัตโนมัติ (**ปวช.** vs **ปวส.**) เพื่อป้องกันการกรอกข้อมูลไม่ตรงหลักสูตร
* **ระบบอัปโหลดเอกสารหลักฐาน**:
  * รองรับรูปถ่ายหน้าตรง 1.5 นิ้ว, สำเนาบัตรประชาชน, สำเนาทะเบียนบ้าน และใบแสดงผลการเรียน (รบ./ปพ.1)
  * จำกัดประเภทไฟล์ (JPG, PNG, PDF) และขนาดไม่เกิน 5 MB
* **ระบบตรวจสอบสถานะการสมัคร (Status Tracker)**:
  * ค้นหาข้อมูลได้สะดวกรวดเร็วด้วยเลขประจำตัวประชาชน 13 หลัก
  * แสดงแถบความคืบหน้า 4 ขั้นตอน: *1. ยื่นใบสมัคร -> 2. ตรวจสอบเอกสาร -> 3. ประกาศผลคัดเลือก -> 4. มอบตัว & ออกรหัสนักศึกษา*
  * แสดงข้อความหมายเหตุและคำแนะนำจากเจ้าหน้าที่
  * รองรับการอัปโหลดแก้ไขเอกสารเพิ่มเติมเมื่อสถานะเป็น "เอกสารไม่สมบูรณ์"

### 2. รูปแบบเอกสาร PDF ใบสมัครและใบมอบตัว
* **ใบสมัครเข้าศึกษาต่อ (Application Form PDF)**:
  * จัดหน้าขนาด A4 สวยงามตามมาตรฐานราชการ พร้อมรองรับภาษาไทย Sarabun
  * รหัสบาร์โค้ด (Vector SVG Code 128) และ QR Code สำหรับยิงสแกนค้นหาในวันมอบตัว
  * ตารางตรวจสอบเอกสารหลักฐาน (Checklist) และช่องลงนามผู้สมัคร/เจ้าหน้าที่
* **ใบมอบตัวและสัญญาค้ำประกัน (Enrollment & Guarantee Agreement PDF)**:
  * ระบุรหัสนักศึกษาที่ออกโดยระบบ
  * เงื่อนไขและข้อตกลงการปฏิบัติตามวินัย 5 ข้อ
  * ช่องลงนามนักเรียน, ผู้ปกครอง/ผู้ค้ำประกัน, พยานอาจารย์ที่ปรึกษา, และหัวหน้างานทะเบียน

### 3. ส่วนสำหรับเจ้าหน้าที่และผู้ดูแลระบบ (Admin & Back-end Dashboard)
* **แดชบอร์ดสรุปสถิติแบบเรียลไทม์ (Analytics Dashboard)**:
  * การ์ดสรุปยอดผู้สมัครทั้งหมด, รอตรวจสอบ, ผ่านคัดเลือก, มอบตัวแล้ว
  * กราฟโดนัทแสดงสัดส่วนผู้สมัครแยกตามสาขาวิชา
  * กราฟแท่งเปรียบเทียบระดับชั้น ปวช. และ ปวส.
  * กราฟสถิติช่องทางการรับรู้และแนะแนว (ครูแนะแนว, โซเชียลมีเดีย ฯลฯ)
* **ระบบจัดการและตรวจสอบข้อมูลผู้สมัคร (Review & Action Drawer)**:
  * ตารางกรองข้อมูลตามระดับชั้น, สาขาวิชา, สถานะ และค้นหาคำสำคัญ
  * หน้าต่างตรวจสอบข้อมูลเชิงลึกพร้อมดูไฟล์แนบ
  * ปุ่มเปลี่ยนสถานะด่วน: *อนุมัติผ่านการคัดเลือก*, *แจ้งเอกสารไม่สมบูรณ์ (พร้อมระบุเหตุผล)*
* **ระบบออกรหัสนักศึกษาและจัดการการมอบตัวอัตโนมัติ**:
  * สร้างรหัสนักศึกษามาตรฐาน ศธ. อัตโนมัติ เช่น `68201010001` (ปี 68 + ปวช.2 + สาขาช่างยนต์ 0101 + ลำดับ 0001)
* **ระบบส่งออกข้อมูลมาตรฐาน ศธ.02 (Export to ศธ.02)**:
  * ส่งออกเป็นไฟล์ **Excel (.xlsx)** ที่จัดสไตล์และคอลัมน์ตรงตามโครงสร้าง 33 ฟิลด์ของระบบ ศธ.02
  * ส่งออกเป็นไฟล์ **CSV (.csv with UTF-8 BOM)** รองรับการเปิดใน Excel ภาษาไทยไม่เพี้ยน

## 🚀 วิธีการเปิดใช้งานระบบ

1. ดับเบิ้ลคลิกไฟล์ `run_server.bat` ในโฟลเดอร์นี้ หรือเปิด PowerShell แล้วพิมพ์:
   ```powershell
   & "C:\Users\TL\AppData\Local\Programs\Python\Python312\python.exe" -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload
   ```
2. เปิดเบราว์เซอร์ไปที่: **`http://127.0.0.1:8000`**
3. ระบบจะทำงานเต็มรูปแบบพร้อมข้อมูลตัวอย่าง (Sample Applicants) ให้ทดลองใช้งานได้ทันที
